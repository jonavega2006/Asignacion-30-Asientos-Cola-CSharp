# Asignacion-30-Asientos-Cola-CSharp
Proyecto desarrollado en C# utilizando Programación Orientada a Objetos y la estructura de datos COLA (FIFO). El sistema simula la asignación de 30 asientos en orden de llegada, aplicando conceptos de estructuras lineales. Trabajo académico correspondiente a la Guía de Prácticas #02 – Estructuras de Datos.
